Set up your sourcing pipeline

Paste your keys. Your own n8n configures itself. Nothing leaves your workspace.

Connect this n8n

Setup uses your n8n API key to create connections and install the pipeline in this n8n. The key is used for this setup only and is never saved.

Where to get it: in n8n open Settings → n8n API → Create an API key. The n8n API isn't available on n8n Cloud's free trial.

Connect your tools

Each key is tested before it's saved. OpenAI and Serper are required; the rest add more sources.

Your details

Used in the AI scoring prompt, your search form and your outreach emails.

Advanced: your own sign-in apps (self-hosted n8n only)

n8n Cloud signs you in to Google and Slack with its own apps, so leave these empty there. On self-hosted n8n, create an OAuth app in Google Cloud (Sheets, Drive and Gmail APIs enabled) and, if you use Slack, a Slack app, then paste their client ID and secret.

Sign in once

First we create your connections in n8n. Then open each sign-in link, click Sign in on the page that opens, and come back here.

Launch your pipeline

One click. Your results sheet, Drive folder and pipeline are created in your own accounts.

✓ You're live

Open your search form, describe the role, and your ranked shortlist lands in your sheet. This setup page has switched itself off.
