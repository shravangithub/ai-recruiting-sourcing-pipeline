Automatic checks

This page runs a few simple client-side checks to help you find the problem quickly.

  • Is this page served from a GitHub Pages domain?
  • Does docs/index.html exist in the repo (raw-check)?
  • Is the Pages build configured to main:/docs? See Pages settings.

Note: the raw file existence check uses raw.githubusercontent.com. If you used a different branch or path, update the commands below.

If you see 404 or wrong page — step-by-step fixes

  1. Confirm the file exists: open https://github.com/shravangithub/ai-recruiting-sourcing-pipeline/tree/main/docs and verify an index.html file is present.
  2. If missing, add this file to docs/index.html (use the green "Add file" button or push via git).
  3. Confirm Pages source matches where the file lives: Settings → Pages → Branch = main, Folder = /docs. Click Save if you changed it.
  4. Wait ~30–90 seconds and refresh the Pages URL. Builds can take a short moment.
  5. If it still fails, view the Pages build log in Settings → Pages (a banner appears when a build fails), or open Actions for Pages build details.
  6. If you lack admin access or Save is disabled, ensure you're signed in as the repo owner (shravangithub) or request admin rights.

Commands you can run locally (copy & paste)

Quick raw-file check — returns HTTP headers for the raw file:

curl -I https://raw.githubusercontent.com/shravangithub/ai-recruiting-sourcing-pipeline/main/docs/index.html

Check Pages configuration via GitHub API (public info):

curl -H "Accept: application/vnd.github+json" https://api.github.com/repos/shravangithub/ai-recruiting-sourcing-pipeline/pages

If you want to set Pages source via API (requires a token with repo scope):

export GITHUB_TOKEN=ghp_xxx
curl -X PUT -H "Authorization: Bearer $GITHUB_TOKEN" -H "Accept: application/vnd.github+json" \
  https://api.github.com/repos/shravangithub/ai-recruiting-sourcing-pipeline/pages \
  -d '{"source":{"branch":"main","path":"/docs"}}'

Common root causes

  • No index file at the published path (e.g., docs/index.html missing).
  • Wrong branch/folder selected in Pages settings (e.g., publishing from root while files are in docs/).
  • Build error (Pages attempted to build and failed — check build logs in Settings → Pages or Actions).
  • Permissions — you're not an admin so Save is disabled.
  • Timing — just created files or changed settings; wait 30–90s for propagation.
